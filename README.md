# کیبورد هوشمند فارسی (اندروید ۷ تا ۱۶)

چیدمان استاندارد فارسی/انگلیسی، شیفت (اعراب و حروف خاص)، نیم‌فاصله، نمادها، ایموجی، سه تم، لرزش، حذف با نگه‌داشتن.
دکمه 🌐: تغییر زبان (نگه‌داشتن = لیست کیبوردها). دکمه ⇧: شیفت (نگه‌داشتن = قفل).

## ساخت APK
پوشه را در یک مخزن GitHub بگذارید؛ بعد از push، در تب Actions کار «Build APK» اجرا می‌شود و فایل APK در Artifacts قرار می‌گیرد.
یا در Android Studio باز کنید: Build > Build APK.
